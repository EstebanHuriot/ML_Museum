# ML_Museum

My goal here is to gain a deeper understanding of machine learning by recreating different models from scratch. </br>
This work is also largely based on books such as 'Hands on Machine Learning with Scikit Learn, Keras and TensorFlow' by Aurélien Géron or 'Quand la machine apprend' by Yann LeCun.
</br>
</br>
Each section combines:
- intuitive explanations
- mathematical foundations
- experiments
</br>

## Structure

The exploratory work is located in `/notebooks`, while the more functional, reusable, library-like code is organized in `/src`.
